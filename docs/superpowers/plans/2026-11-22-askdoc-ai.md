# Ask Doc AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deployable Next.js RAG app where an anonymous visitor uploads PDFs, asks questions, and gets streamed answers grounded in the document with clickable page citations.

**Architecture:** Browser uploads PDFs directly to a private Supabase Storage bucket via a signed URL, then drives a resumable two-phase ingestion (extract/chunk, then embed in batches). Chat embeds the question, retrieves top chunks from pgvector via an RPC, streams a grounded answer with Gemini, and emits retrieval metadata as structured sources. A server-only service role is used for all database and Storage operations; RLS denies public table access.

**Tech Stack:** Next.js 16.4.6 App Router, React 19.3.1, TypeScript, Tailwind CSS 4.3.5, shadcn/ui, Vercel AI SDK 7.0.179, `@ai-sdk/google` 4.0.124, `@ai-sdk/react` 4.0.183, `@supabase/supabase-js` 2.119.2, `unpdf` 2.2.1, `@langchain/textsplitters` 1.0.2, `react-pdf` 11.1.0 + `pdfjs-dist` 6.5.438, Zod 4.6.7, Vitest 5.1.1, pnpm, Node.js 22.

**Spec:** `docs/superpowers/specs/2026-11-22-askdoc-ai-design.md`

## Review Focus

These are the inputs/conditions most likely to break a real user, even though the spec's happy path does not mention them. Each line is pinned to a test in the owning task.

1. **Scanned or text-poor PDFs** — a PDF with no extractable text, or a short page that actually contains the answer, must produce `PDF_NO_TEXT` only when the whole document is unusable; short pages must be retained. (Task 8.)
2. **Interrupted upload or duplicate ingest** — a closed tab, expired upload URL, or two tabs calling ingest must resume without duplicate chunks and must not deadlock. (Tasks 6, 11, 12.)
3. **Gemini 429/timeouts** — embedding progress must survive, the UI must offer a clear resume path, and chat must not persist duplicate messages. (Tasks 10, 11, 16.)
4. **Prompt injection and invalid citations** — instructions inside a PDF must not change behavior, and `[Halaman N]` markers outside the retrieved pages must be removed from both the stream and stored message. (Tasks 15, 18, 19.)
5. **Expired/deleted document with an open chat or PDF modal** — the API must return 410/404, the UI must not crash, and the Storage URL must not remain usable. (Tasks 20, 21, 22.)

- [ ] **Step 3: Implement the modules**

Implementation decisions:

- `security.ts` compares the `Origin` host to `request.nextUrl.host`; allow requests with no `Origin` (curl/tests). Throw `AppError('FORBIDDEN', 403, 'Permintaan tidak diizinkan.')`.
- `readSessionId` reads `request.cookies.get(SESSION_COOKIE)?.value` and validates with a UUID regex.
- `ensureSession` checks `rag_sessions` for the cookie id; if missing, creates a new UUID and inserts it. It never trusts a cookie id without a row.
- Cookie setting is done on `NextResponse` from the route handler, not via `next/headers`.
- `checkRateLimit` calls `supabase.rpc('rag_check_rate_limit', { p_key, p_limit, p_window_seconds })` and takes the first row. Throw `AppError('INTERNAL_ERROR', 500)` if the RPC errors.
